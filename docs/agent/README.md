## 命名约定

* **版本目录**：`v<major>.<minor>.<patch>`。
* **阶段编号文件**：`NN-<主题>.md`，`NN` 为**跨版本的全局流水号**（00–04 属 v1.1.1，05 属 v1.1.2，06 属 v1.2.3），便于按时间顺序阅读。
* **日志**：一律放在对应版本的 `logs/` 下。文件名含 `1.1.2` 或 `BEFORE-FIX` 的归 v1.1.2，其余归 v1.1.1。
* **`BEFORE-FIX`**：修复前的对照日志，与同名的修复后日志配对阅读。

## 维护须知

1. **新增文档请放入对应版本目录**，不要留在 `docs/agent/` 根下。
2. **日志例外规则**：`.gitignore` 里有 `!docs/agent/\*\*/logs/\*.log`，使日志**随文档一并入库**（这是有意的——见各版本 `run-log.md` 的留痕要求）。若新增版本目录，该规则会**自动覆盖**，无需改动。
3. **审查发现的处理范式**：沿用 `N-xx` / `IMP-xx` 编号 + 「原因 + **重启条件**」；判定不成立的必须给出反证。
4. 若某文档同时横跨多个版本（如通用 SOP），放在 `docs/` 根而非本目录。
